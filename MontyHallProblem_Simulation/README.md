# Monty Hall Problem Simulation

An interactive command-line simulation of the Monty Hall game show problem.
The program runs the same player choice repeatedly and compares the win rates
for keeping that choice and switching after the host reveals a losing door.

## Run

```bash
python MontyHallProblem_Simulation.py
```

Enter a positive number of simulations and a starting door (`0`, `1`, or `2`).
For enough runs, switching approaches a two-thirds win rate while staying
approaches one third.
