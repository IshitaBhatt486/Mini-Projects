# Mini Projects

This repository contains independent learning and hardware projects. Each
project remains in its own top-level folder; `Other/` is intentionally left
unchanged.

| Project | Description |
| --- | --- |
| `Avoid-the-obstacle-game/` | Luma, a WebGL tap-to-fly game. |
| `BackPropagation/` | Backpropagation notebook. |
| `CPU_Clock/` | KiCad design for an 8-bit CPU clock module. |
| `DualPortRAM/`, `SinglePortRAM/`, `ROM/` | Verilog memory examples and test benches. |
| `MontyHallProblem_Simulation/` | Interactive Python Monty Hall simulation. |
| `Resnet-notebook-Takopi/` | TensorFlow ResNet-50 cattle-breed classifier. |
| `RISCV_SingleCycleProcessor/` | Verilog 32-bit RISC-V single-cycle processor. |
| `space_invaders/` | Pygame Space Invaders project. |
| `SpellBee/` | Browser spelling quiz. |
| `YouTube Clone/` | Static YouTube interface clone. |

Use the README inside a project folder for setup and usage instructions.
